# Tecnologia

## Stack

- **React** (biblioteca de UI)
- **Vite** (build e dev server)
- **TypeScript** (linguagem)
- **Tailwind CSS** (estilização)

## Gerenciador de pacotes

- **npm**, salvo se o projeto indicar outro mais adiante.

## Fase atual do projeto

- App **inicialmente frontend-only**, com **dados mockados**.
- **Não implementar backend real** nesta fase.
- Quando for pedido apenas mock visual, não criar backend de verdade.

## Regras de dependências

- **Não adicionar dependências grandes sem aprovação.**
- **Não usar bibliotecas visuais pesadas** (UI kits, frameworks de componentes
  completos, libs de animação pesadas) **sem autorização**.
- Instalar apenas o necessário para a etapa em andamento.

## Princípios técnicos

- Priorizar **componentes simples, reutilizáveis e fáceis de manter**.
- Código limpo, simples e coerente com o projeto existente.
- TypeScript bem tipado, evitando `any` quando possível.
- Estilização com utilitários do Tailwind, sem CSS complexo desnecessário.
