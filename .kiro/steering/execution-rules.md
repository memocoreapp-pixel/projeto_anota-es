# Regras de Execução

## Antes de qualquer alteração

Sempre explicar:

1. o que foi entendido;
2. quais arquivos pretende alterar;
3. qual será o impacto visual ou técnico;
4. o que será preservado;
5. o que não será alterado.

## Regras

- **Não recriar a interface do zero sem autorização.**
- **Não alterar nomes, rotas ou estrutura central sem pedir confirmação.**
- **Não adicionar funcionalidades grandes sem separar em etapas.**
- **Não implementar backend real quando for solicitado apenas mock visual.**
- **Não adicionar mapa visual nesta etapa**, salvo pedido explícito.
- Não exagerar em gradientes, sombras, 3D, ilustrações infantis ou aparência de
  videogame.
- Priorizar UI limpa, profissional, acessível e intuitiva.

## Fluxo de trabalho

- Sempre trabalhar em **etapas pequenas**.
- Sempre **preservar o que já está funcionando**.
- Sempre **confirmar o plano antes de editar muitos arquivos**.
- Sempre gerar código **limpo, simples e coerente** com o projeto existente.

## Aprovação obrigatória

- Não avançar para a criação do app sem aprovação explícita.
- Não instalar dependências além do necessário para a etapa atual sem aprovação.
