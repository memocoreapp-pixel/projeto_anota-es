# Direção Visual

## Identidade

- **Fundo claro.**
- **Roxo como cor principal.**
- Aparência de **produto real**, profissional e acessível.
- Visual agradável para **público amplo**, não apenas para designers.

## Componentes e layout

- **Cards com bordas arredondadas.**
- **Pouca sombra.**
- **Boa hierarquia visual.**
- **Tipografia legível.**
- **Ícones simples e profissionais.**
- Bom espaçamento e respiro entre elementos.

## O que evitar

- Excesso de gradientes.
- Excesso de sombras.
- Efeitos 3D.
- Ilustrações infantis.
- Aparência de videogame.

## Princípio geral

Priorizar uma **UI limpa, profissional, acessível e intuitiva**. O usuário comum
deve entender a interface sem esforço. Beleza a serviço da clareza, nunca o
contrário.
